ℹ️ About this network

Each buoy has its own detailed dashboard that updates every hour: two Sofar Spotter wave buoys (waves, wind estimate, pressure, and Smart Mooring sensors) and four BlueSonde water-quality buoys (temperature, salinity, dissolved oxygen, turbidity, and chlorophyll or tryptophan). This page reads the latest numbers straight from those dashboards each time it loads and refreshes itself every 10 minutes.

    Wave data: Sofar Ocean. Water-quality data: BlueSonde via CUMULUS (Coastal Measures). Tide predictions: NOAA. Built and maintained by the University of New England.
